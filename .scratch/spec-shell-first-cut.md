Part of #2

## Problem Statement

学习者需要在同一款应用里学英语口语和学校数学，但两种用法互斥、又不该靠账号或档案来区分身份。在英语主路径与数学主路径尚未实现之前，必须先证明：这是一个应用、两种学习模式，经共享外壳进出，且每种模式的主界面不会同时出现。

## Solution

交付一个可运行的客户端应用，打开即进入**外壳**（左右分区：英语 | 数学）。学习者点选一侧进入对应**学习模式**的占位主界面；从该界面**退出**回到外壳。不设学习者身份、不要账号。进入某学习模式时，另一侧主界面不在。退出时按已锁决策写回**本机历史记录**（空白过程不进列表；两模式各有一份、互不共享）。

## User Stories

1. 作为学习者，我希望打开应用时直接看到外壳的左右分区（英语 | 数学），以便选择今天要用的学习模式。
2. 作为学习者，我希望在外壳上点选「英语」进入英语学习模式，以便开始（或将来的）英语会话。
3. 作为学习者，我希望在外壳上点选「数学」进入数学学习模式，以便开始（或将来的）数学学习过程。
4. 作为学习者，我希望在任一学习模式里能退出回到外壳，以便切换学习模式或暂时离开。
5. 作为学习者，我希望处于英语学习模式时看不到数学主界面，处于数学学习模式时看不到英语主界面（含 NPC 会话区域），以便两种用法保持互斥。
6. 作为学习者，我希望从外壳进入某学习模式时，该模式以空白**当前过程**开始，以便每次进入都是干净起点（除非我手动加载历史）。
7. 作为学习者，我希望从学习模式退出时，若当前过程非空白，则写回该学习模式的本机历史列表；若仍空白，则不进列表，以便本机留痕但不制造空条目。
8. 作为学习者，我希望英语与数学各自拥有独立的本机历史列表、互不共享，以便两科进度不会混在一起。
9. 作为学习者，我希望在本机历史列表里用「时间 + 过程开头摘录」辨认条目（无单独标题字段），以便找到以前的过程。
10. 作为学习者，我希望可以手动从列表加载某条历史到当前过程，以便继续以前的学习。
11. 作为学习者，我希望可以删除列表中的条目（含当前正在编辑的那条）；删完后若当前为空则处于空白当前过程且不可找回，以便管理本机空间。
12. 作为学习者，我希望本机历史列表不封顶，以便长期保留过程。
13. 作为学习者，我希望应用不要求登录、注册或任何学习者身份，以便开箱即用。
14. 作为学习者，我希望英语与数学占位主界面足以辨认「我已在该学习模式中」，以便在完整主路径实现前验证导航与互斥。
15. 作为学习者，我希望刷新或再次打开应用后仍能看到此前写回的本机历史（在同一浏览器/设备上），以便本机记录持久。

## Implementation Decisions

### 范围与导航

- 第一刀只证明**同一应用、两种学习模式**；英语主路径（NPC、实时语音、TTS、辅助动作）与数学主路径（画布、拍照、文字、分析、GeoGebra）本 spec **不实现**，各学习模式主界面用**占位**即可，但必须可进入、可退出、可辨认模式名。
- 全局导航状态为三态：`外壳` | `英语学习模式` | `数学学习模式`。仅一态可见；切换经外壳或「进入 / 退出」动作，不允许多态并存。
- **外壳**布局：左右分区，左（或等价一侧）为英语入口，右为数学入口；不是任一种学习模式的主界面，不展示本机历史列表（历史在各模式主界面或次级入口访问——具体布局属雾，本 spec 只要求能力存在且可手动加载/删除）。
- 每种学习模式提供明确的**退出**控件，退出目标始终是外壳。

### 本机历史记录

- 存储介质：浏览器本机持久化（如 `localStorage` 或 IndexedDB）；无服务端、无账号同步。
- 数据结构（概念层）：每种学习模式独立列表；每条记录含时间戳、过程内容序列（第一刀占位过程可仅含模式标识或极简摘录来源）、用于列表展示的**开头摘录**。
- **当前过程**：进入模式时为空；加载历史时替换当前过程；退出时若非空则 append 或 update 列表（新开始的过程退出时追加新条）。
- 空白判定：第一刀可定义为「无任何学习者产生的内容」；占位 UI alone 不算内容。
- 删除：支持删列表项；若删的是当前加载项，当前过程清空为空白且不可 undo。
- 两模式规则对称。

### 模块与接口（seam 层）

- **应用导航（Application navigation）**：拥有三态导航与「进入学习模式 / 退出到外壳」转移的唯一模块。对外暴露：当前可见层、进入(英语|数学)、退出、以及供 UI 订阅的状态。这是本 spec 的**主 seam**——测试只驱动该接口（或等价 UI 行为），不断言内部路由库选型。
- **本机历史记录（Local learning history）**：按学习模式读写列表与当前过程的模块。对外暴露：加载列表、加载条目到当前、写回当前、删除条目、判定空白。导航模块在「进入模式」与「退出」时调用它；测试可单独测持久化行为或通过导航集成测。

### 技术取向（非绑定）

- 单页 Web 应用即可；具体框架不在 spec 中锁定。
- 第一刀不接入后端 API、不接入 GeoGebra、不接入语音/NPC。

## Testing Decisions

- 只测**外部行为**：给定导航动作与本机存储预置，断言可见层与学习模式互斥、退出回外壳、历史写回/不写回/加载/删除规则。
- **主 seam**：应用导航 —— 用例覆盖故事 1–5、14（三态、互斥、退出）。
- **次 seam**：本机历史记录 —— 用例覆盖故事 6–12、15（空白/current、写回、分模式、摘录、删除含当前、持久化）；可与导航集成测试，也可在 seam 边界用 fake storage 单测。
- 不测：具体 CSS 分区像素、框架内部 hook、占位文案字面量。
- 先例：绿地项目，无现有测试；建立端到端或组件级行为测试一套即可（如 Playwright + 单元测 seam 模块）。

## Out of Scope

- 英语主路径：NPC、3D、实时语音、TTS、辅助动作、会话逻辑
- 数学主路径：画布、画布痕迹、拍照、文字输入、语音转写、提交、分析、GeoGebra 命令与渲染
- 学习者账号、登录、云同步、档案
- 老师备课、班级课堂、学校后台
- 两种学习模式主界面的最终布局与视觉（占位即可）
- 学段与内容范围
- 外壳之后第二刀切英语还是数学（留给后续 spec/ticket）
