# 沉浸式英语口语陪练（v1）设计

日期：2026-08-21  
状态：待实现（本文件为已对齐的产品 spec）

## 1. 目的与成功标准

面向任何想练英语口语的人。场景提供沉浸氛围，核心是与 NPC **自由口语对话**。NPC **完全代入场景身份**（例如收银员只聊购物、结账），不主动当英语老师、不打断来纠错、不布置通关任务。

v1 成功标准：在 Windows 上打开 Godot 导出的桌面程序，进入一张中性室内地图，能走路并切换第一/第三人称，自动锁定 NPC 后用英语语音对话（豆包全双工，默认可打断），字幕实时出现，退出后历史里能看到「模型总结的标题 + 全文」。

## 2. 范围

### 2.1 做（v1）

- Godot 4.3+ 桌面端（先 Windows）
- 一张中性室内地图、一个可行走玩家、一个可配置人设的 NPC
- 点选锁定 NPC；进场景自动锁定最近 NPC
- 豆包端到端实时语音（全双工 WebSocket），客户端直连
- 对话字幕 HUD（默认右上角，可改为底部居中）
- 会话结束时生成标题并本地保存；游戏内只读历史列表

### 2.2 明确不做（v1）

- 超市/教室/商场等成品主题地图（视觉替换见 `2026-08-21-game-realistic-assets-design.md`）
- 账号、云同步、语音网关、应用商店上架
- 手机包（架构允许以后导出，v1 不交付 Android/iOS）
- 录音回放、发音评分、语法纠错老师模式
- 多玩家、物品栏、任务系统、自研 VAD

## 3. 架构

四个模块只通过窄接口通信。Godot 工程放在仓库 `game/`，与 `.agents/` 分离。游戏逻辑用 GDScript。

| 模块 | 职责 | 不知道的事 |
|------|------|------------|
| 世界 | 房间场景、玩家移动与相机、NPC 位移与动画 | 豆包协议、密钥、保存格式 |
| 互动 | 当前目标 NPC、点选、进场最近锁定 | PCM、WebSocket |
| 实时语音 | 开/关会话、送麦、播 NPC 音频、字幕与听/说状态事件、打断开关 | 怎么走路、HUD 画在哪 |
| 会话 | 时间线、结束规则、标题、本地存储、HUD 数据 | 音频设备 |

人设是 Godot Resource（显示名、给模型的人设文案、音色 ID）。换资源即换角色，不必改世界或语音协议代码。

语音模块实现为接口：`start(persona)` / `stop()` / 音频与文本信号。v1 实现是豆包全双工 WebSocket；以后手机可换成官方 SDK，世界与互动不改。

密钥只读本机配置（`user://` 下的配置文件），不进 Git、不打进导出包的明文模板仓库。v1 不做短时 token 网关。

## 4. 世界、玩家与 NPC

### 4.1 场景

一张独立的中性室内场景：出生点、可行走地面、一个 NPC。用另一张场景资源替换外观时不改玩家控制器和语音模块（见 `2026-08-21-game-realistic-assets-design.md`）。

### 4.2 玩家

- `CharacterBody3D`，WASD 移动，鼠标转向。
- 同一套移动、两套相机：第一人称在头部（隐藏玩家网格）；第三人称身后弹簧臂。
- 一个按键切换人称。切换不改变当前目标、不中断语音会话。

鼠标与点选：

- 第一人称默认捕获鼠标。准星中心射线 + 左键 = 点选该处的 NPC。
- `Alt` 暂时放出鼠标，可直接点 NPC 网格。
- 第三人称默认显示鼠标，左键点 NPC 网格。

### 4.3 锁定规则

- 场景树就绪后，锁定距离玩家最近的 NPC（v1 只有一个，结果就是他）。
- 无 NPC 则不锁定、不开麦。
- 点选当前已锁定对象：无操作。
- 点选另一个 NPC：先按第 6 节结束并保存当前会话，再锁定新目标并开新会话。
- 走路不改变锁定、不断开会话。

v1 交付一个 NPC；锁定与「换目标即结束会话」按 N 个 NPC 实现，测试场景可放两个 NPC。

### 4.4 NPC

- 在室内沿巡逻点或小范围闲逛。
- 被锁定且处于 Listen 或 Talk 时停下并转向玩家。
- 四态动画，由互动 + 语音状态驱动，不写死职业逻辑：
  - **Idle / Walk**：未在听、未在说
  - **Listen**：用户正在说话
  - **Talk**：正在播放 NPC 音频（可叠一个通用手势）

人设资源字段（缺一不可）：`id`（写入存档的 `persona_id`）、`display_name`、`character_manifest`（豆包强人格人设，须约束 **只说英语**、只扮演该身份、不主动当老师）、`voice_id`。

## 5. 语音链路

协议：火山引擎豆包语音 [端到端实时语音接入必读](https://docs.volcengine.com/docs/6561/2549732?lang=zh) 与 [全双工版本](https://docs.volcengine.com/docs/6561/2549778?lang=zh)。使用 **Strong Character（强人格）** 版本，以便收银员等人设稳定。

### 5.1 何时连、何时断

- **开：** 锁定目标且人设资源有效之后，立即建连并采集麦克风（进场景自动锁定 ⇒ 进场景即开麦）。
- **关：** 换 NPC、离开当前地图、按下退出。关麦、停播、断开 WebSocket。
- 走路、切换人称：不断连。

### 5.2 行为

- 锁定期间持续送麦。用户停顿由豆包判停（可用其 `end_smooth_window_ms`，v1 用文档默认值，不做自研 VAD）。
- 收到 NPC 音频则流式播放（Godot 流式播放器）；同时发 Talk 状态。
- **打断默认开：** 用户开口则停止当前 NPC 播放，转入听用户。设置可关；关闭后，NPC 播放期间 **不上行麦克风**（或不向模型发送可打断的音频），本句播完后再恢复上行。
- 字幕只使用接口返回的用户文本与 NPC 文本，游戏内不再跑一套 ASR。

### 5.3 音频与配置

- 采集：麦克风总线 PCM，格式按全双工文档要求转换后上传。
- 播放：下行 PCM 写入流式播放器。
- 凭证：本机配置中的火山引擎实时语音鉴权参数。缺失则走第 7 节「没密钥」。

## 6. 字幕、结束与保存

### 6.1 时间线

每条记录：`role`（`user` | `npc`）、`text`、`at`（Unix 毫秒）。只在会话进行中追加。HUD 订阅这条时间线：默认贴屏幕右上角，设置改为底部居中。只渲染最近若干条，可滚动看本段全文。设置写入 `user://settings.cfg`，与打断开关一起持久化。

### 6.2 结束条件（仅此三项）

1. 点选另一个 NPC  
2. 卸载当前地图（回主菜单或换场景）  
3. 退出程序  

暂停菜单里的「退出场景」与关闭窗口走同一套结束逻辑。没有「仅挂断但仍留在场景」按钮。

结束顺序：停麦 → 断语音连接 → 若本段至少有一条非空文本则保存 → 清空当前时间线（进入新会话或回菜单时）。

### 6.3 保存格式

目录：`user://conversations/`。每段一个 JSON 文件。

```json
{
  "id": "uuid",
  "title": "在货架前问牛奶在哪",
  "started_at": 0,
  "ended_at": 0,
  "scene_id": "indoor_neutral",
  "persona_id": "cashier_default",
  "turns": [
    { "role": "user", "text": "...", "at": 0 },
    { "role": "npc", "text": "...", "at": 0 }
  ]
}
```

标题：将本段 `turns` 交给火山引擎豆包 **文本 Chat API** 一次非流式调用（与语音同一账号体系，模型名放本机配置，例如 `doubao-pro` 一类已开通模型）。系统提示要求：只输出不超过 20 个汉字的中文标题，不要引号和解释。正文保持说话原文（英语）。标题失败则后备为：首条用户非空文本截断到 20 字；若没有用户文本，则用 `对话 YYYY-MM-DD HH:MM`。标题失败 **不得** 丢弃正文。

无非空 `turns` 的会话不写文件。

### 6.4 历史 UI

主菜单中的只读列表，按 `ended_at` 倒序，点开查看标题与全文。v1 不存音频、不提供编辑或删除。

## 7. 错误处理

原则：场景仍可走；已产生的字幕尽量保留；不向玩家展示堆栈。

| 情况 | 表现 |
|------|------|
| 无密钥或密钥无效 | 可走、可点选；HUD 提示去本机配置填写凭证；不自动重连刷屏 |
| 连不上或中途断线 | 停播、停麦；HUD 显示「连接断开」和重试；重试成功则 **同一段** 时间线继续；结束时仍保存已有文本 |
| 无麦克风或权限拒绝 | HUD 说明需要麦克风；不进入 Listen、不假装在听 |
| NPC 音频卡顿或超时 | 回到 Idle/Listen；打断开启时允许用户再开口 |
| 标题生成失败 | 后备标题，正文照写 |
| 磁盘写入失败 | 提示「未保存」；本段仍留在内存，允许再试一次保存 |
| 误拾噪音 / 误打断 | 判停交给豆包；用户可在设置中关闭打断 |

密钥与网络错误只写本地日志，不写入 `turns`。
